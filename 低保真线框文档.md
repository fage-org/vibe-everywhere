# Vibe Everywhere 低保真线框文档

## 1. 目的

本文档基于 `需求文档.md` 与 `页面信息架构与交互说明.md`，提供首发版本关键页面的低保真线框，便于后续产品评审、UI 设计和前端实现拆分。

本文档聚焦：

- 手机端关键页面
- 桌面端关键页面
- 关键状态与交互入口

本文档不涉及视觉风格、色彩、品牌语言和高保真组件细节。

## 2. 线框约定

### 2.1 标记说明

- `[按钮]`：可点击按钮
- `(输入框)`：输入或搜索区域
- `<标签>`：切换标签
- `...`：省略内容或滚动区域
- `*`：重要状态提示

### 2.2 页面优先级

本次优先覆盖以下页面：

- 手机端
  - 服务器地址配置
  - 主机配对
  - 活动会话列表
  - 新建会话
  - 会话详情
  - 权限审批
  - 主机 / workspace
  - 归档列表
  - 设置
- 桌面端
  - 主应用框架
  - 活动会话工作台
  - 主机与 workspace 管理
  - 归档中心
  - 设置

## 3. 手机端低保真线框

## 3.1 启动页 / 服务器地址配置

用途：

- 首次连接自建服务器
- 修改已有服务器地址

```text
+--------------------------------------------------+
| Vibe Everywhere                                  |
|                                                  |
| 连接你的服务器                                   |
|                                                  |
| 服务器地址                                       |
| ( https://your-server.example.com            )   |
|                                                  |
| [测试连接]                                       |
|                                                  |
| 状态: 未连接 / 测试成功 / 测试失败               |
|                                                  |
| [继续]                                           |
|                                                  |
| 说明:                                            |
| - 首次使用需要先连接自建服务器                   |
| - 后续可在设置中修改                             |
+--------------------------------------------------+
```

关键交互：

- `测试连接` 成功后允许继续
- `继续` 后进入设备授权完成页或首页
